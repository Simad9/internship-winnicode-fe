## Dokumentasi Folder src

`assets/` = Menyimpan gambar, ikon, font, atau media lainnya \
`components/` = Buat nyimpen component yang dipake di seluruh pages \
`css/` = Inisial untuk CSS, kayak variabel warna, font, dan google font \
`features/` = Fitur-fitur yang ada di FE \
`layout/` = Buat setting fitur [Gak dipake saat ini] \
`routes/` = Bagian yang mengurusi perpindahan antar halaman \
`auth/` = Buat ngurus auth, jadi harus login terlebih dahulu \
`store/` = Buat menyimpan konfigurasi state management global pake Zustand \
`utils/` = Buat ngatur fngsi helper, format tanggal dll \
